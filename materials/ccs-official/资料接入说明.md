# 学院官网课程与教师资料接入

来源入口为 <https://ccs.cuc.edu.cn/>。本批资料用于毕设中的课程与教师知识问答，保留官网来源、原页发布日期、采集时间与哈希。官网公开资料的助手整理汇编与学校原生文件分别标识。

2026-10-27 完成的资料覆盖 15 个官网栏目、37 个栏目分页和 134 个正文页面。整理 64 份公开人员简介，另保留徐翊焜、陈磊 2 个仅有姓名而没有独立个人页的缺失说明。393 个课程及培训项目条目对应 369 个独立名称，其中 57 条有范围有限的公开内容，336 条仅有名称；这些条目包含历史实践环节和社会培训，不能称为 393 门现行专业课程的完整简介。

正式入库两份 PDF 分别为 28 页教师汇编和 116 页课程索引，解析得到 79 与 512 个片段。原有 34 份文档及其原件哈希保留，全库合计 36 份文档、1297 个片段，其中 4 份为原有虚构示例。144 页合订版用于阅读下载，同一内容不重复入库。

`academic-records-reviewed.json` 为经过范围复核的结构化输入。`pdf-reviewed/学院教师公开简介汇编.pdf` 与 `pdf-reviewed/学院课程公开信息与教师对应索引.pdf` 分别作为“师资信息”和“课程简介”入库。供阅读的合订版在项目 `output/pdf/`，不重复入库。原始采集页面、附件和旧汇编保留用于追溯。

`manifest.json` 记录两份入库 PDF 的 SHA-256、页数、预期切片数、来源页面和资料范围。各篇官方原页日期保存在每份文档的 `source_records` 和 `metadata.source_collection.source_dates`，汇编文档的统一 `published_at` 留空。采集日期不能代替原页发布日期。全院资料的 `major` 与 `cohort` 留空，避免被系统默认的 2023 级计算机专业筛选误排除。

在项目根目录运行以下命令可从已核验原件恢复资料，不调用生成模型：

```powershell
.\.venv\Scripts\python.exe scripts\register_ccs_corpus.py
.\.venv\Scripts\python.exe scripts\bootstrap_knowledge.py
.\.venv\Scripts\python.exe scripts\verify_ccs_retrieval.py --semantic --save-index
```

第一步只生成清单并核查 PDF 的大小、页数、每个条目标题和文字可解析性；第二步沿用项目现有导入器，按文件哈希避免重复导入；第三步使用本机已有检索模型，核查分类、人物与课程标题及来源，并同步保存索引。没有本地语义模型时可省略第三步的 `--semantic`，使用 TF-IDF 做本地验证。单份 PDF 仍受现有 300 页与 10 MB 限制。

导入前先关闭正在运行的应用，并对 `data/knowledge.db` 做 SQLite 一致性备份。导入完成后正常启动系统，启动过程会读取原有语义检索设置并从数据库重建索引；如果应用此前已启动，需要重新启动才能更新其内存索引。此次资料接入不修改生成模型凭据或开启新的付费模型请求。

在“我的知识库”按“师资信息”或“课程简介”查看文档和片段。可使用“仅查看原文（不调用模型）”提问，例如“黄玮老师的研究方向是什么？”、“数据结构由哪些老师讲授？”。系统会按单个人物或课程的标题检索，跨页切片保留该标题。

公开教师简介中“目前”“曾经”等原有时态及原页日期随证据保留，不能把历史讲授记录当作当前学期排课。只有课程名称的条目明确说明缺少公开简介；教学建设参与、授课关系、社会培训和学分课程分别标识。年度招生名额仍从相应招生资料检索，课程考核方式仍从正式课程大纲检索。

同步核验结果保存在 `quality/retrieval-report.json`。它用于资料接入检查，不能当作独立实验数据或生成回答准确率。

TF-IDF 基线核验另存 `quality/retrieval-tfidf-report.json`。在 0.08 阈值下，“黄玮老师的研究方向是什么？”这一长问句未命中，5 个具名问题中其余 4 个命中；不能把该结果描述成所有模式均通过。系统实际使用的本地语义与混合重排序核验，以 `quality/retrieval-report.json` 中记录的模式、阈值和结果为准。

最终本地 BGE 语义索引已恢复为 512 维，检索策略为 `hybrid_rerank`、阈值 0.55；5 个具名师资/课程冒烟问题全部检索到相应条目，未知教师排除及招生年度、课程大纲路由检查通过。再次运行恢复命令时 32 份正式资料均显示已存在，新增数为 0，全库仍为 36 份文档、1297 个片段；已保存的语义索引哈希保持不变。原 34 份文档、706 个切片及原件哈希均核验保留。

导入前的数据库一致性快照与旧索引保存在 `output/backups/ccs-before-import-20261027-172047/`，不含凭据。最终导入、幂等性、索引形状与检索结果摘要在 `quality/import-summary.json`，本批生成 API 调用数为 0。
