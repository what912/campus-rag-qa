# 生成答案人工评分模板

每个问题记录：问题 ID、验证集或测试集、原文件与版本、适用专业年级、参考答案、对应原文页码和片段、模型实际回答、模型和检索配置。

| 指标 | 记录方法 |
|---|---|
| 正确性 | 0=错误；1=部分正确但遗漏关键条件；2=正确且主要条件完整 |
| 证据支持 | 把每条实质性结论与来源片段对应；有无法支持的数字或条件则标出 |
| 引用正确 | 编号存在且引用片段支持对应结论；仅编号存在不算通过 |
| 版本适用 | 回答没有混用专业、入学年级或废止版本 |
| 无依据问题 | 明确说明无法确认，没有补造规定；另统计可回答问题的误拒答 |
| 流程完整性 | 办理入口、所需材料、办理步骤和适用条件是否有文档依据 |
| 时延 | 使用接口返回的 retrieval_ms、generation_ms 和 elapsed_ms |

先人工核对开发问题集，再固定独立测试集。改阈值和提示词只能依据验证集，避免使用测试集调参。尽量由另一名同学或导师复核部分评分，并记录分歧处理方式。模型自动评价只能辅助，不能替代真实依据核对。
