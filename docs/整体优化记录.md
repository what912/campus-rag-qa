# 整体优化记录

日期：2026-10-13。系统 v0.4.0。服务对象为中国传媒大学2023级计算机科学与技术本科生。本轮保留原始模型记录，没有替换历史回答，没有重新加入用户要求删除的4道无依据题。

## 检索与评价

新增 `hybrid_rerank` 规则重排序，保留TF-IDF、BGE与原RRF供对照。规则去除问题通用表达，结合重点词、文件主题、RRF排名和所问信息类型，修复代办材料、施行日期、转专业学期等已知漏检。采用共享类别路由和专业年级筛选，不按题号返回答案。

页面与离线脚本共用证据评价函数，默认K=4。文件名命中、证据片段命中、片段Recall和MRR分开报告；标签找不到对应原文会明确列出，无负例时拒答率为空。

数据来自 `evaluation/results/retrieval-optimization-report.json`。这些19题参与了规则设计，只是开发修复检查，不能当独立测试或生成准确率。检索P95受机器和缓存影响，不直接比较旧生成实验的总耗时。

## 问答与回答核对

优化生成提示：明确检索片段不等于完整文件；通用文件元信息未单独限定年级不等于不适用；检索遗漏不应断言完整文件没有规定。新提示尚未运行新一轮在线对照，质量需后续实测。

新增“仅查看原文（不调用模型）”、回答复制和含证据的Markdown导出。模型启用时也可逐题选择原文模式，便于本地演示。

新增回答核对页，读取保存记录，按题显示四组答案，支持正确性0–2、证据支持、引用支持、评分人、说明和CSV导出。用户评分保存在 `data/reviews`，与原始报告SHA-256绑定；原记录变化时拒绝套用旧评分。

已对57条旧RAG结果的核心目标事实做助手初评，保存于 `assistant-initial-review-20261013.json/.csv`，核对页单独展示。没有把助手初评填入人工评分，也没有宣布正式答案准确率。旧直接组背景不一致，未做效果评分。
