# 临时公网演示

本方式把当前电脑正在运行的毕设系统通过临时 HTTPS 网址提供给其他电脑。当前电脑需要保持开机和联网；它不是云端独立部署。其他电脑只需要浏览器，以及本次演示的账号和密码。

## 开启与使用

1. 先运行项目根目录的 `启动系统.cmd`，等待本机 <http://127.0.0.1:8765> 能正常访问。
2. 双击 `开启公网演示.cmd`。它只复用现有毕设主服务，不重复启动模型。
3. 启动窗口只显示演示网址和访问说明文件位置。账号和密码保存在本机 `output/临时公网访问说明.txt`，不会写入隧道日志或网址。
4. 在其他电脑浏览器打开该 HTTPS 网址，在网页登录页填写账号和密码。可以试问“黄玮老师的研究方向是什么？”或“数据结构由哪些老师讲授？”。

保管好访问说明，只交给需要试用的人。获得账号和密码的人可以操作当前这套系统，包括问答和管理功能；默认仍使用项目已保存的模型设置。可先勾选“仅查看原文（不调用模型）”核对资料。

## 停止与重新开启

双击 `停止公网演示.cmd`，只关闭本项目的临时隧道和访问保护代理，保留本机毕设服务。关闭浏览器不会停止演示。睡眠、断网、关机或停止隧道后，其他电脑将不能访问。

免费隧道域名会变化，重新开启后以访问说明中的新网址为准。若启动脚本确认已有本项目的代理和隧道在运行，会复用当前演示，避免开启重复进程。它不会自动设置开机启动。

服务也可能在 SSH 连接仍存活时轮换域名。后台轻量助手会同步最新域名到访问说明和登录配置；旧域名失效时，需要从说明中复制新地址，并重新登录。该助手不发送网络请求，停止隧道后会自行退出。

## 本机文件与端口

- 主应用继续仅监听 `127.0.0.1:8765`。
- 受保护代理仅监听 `127.0.0.1:8767`；SSH 隧道只转发这个代理。
- 公网采用有时限的签名会话，Cookie 设置为 Secure、HttpOnly、SameSite=Strict，登录表单只提交到本次 HTTPS 网址；本机代理检查仍使用 BasicAuth。访问口令变更后，旧会话失效。
- `data/share-access.json` 保存随机访问口令、固定本机上游和当前公网来源地址。代理在每次请求时重新读取它。
- `data/share-state.json` 保存代理与隧道的 PID、当前网址和时间；不保存口令。
- `.tools/share/ssh_config` 和 `.tools/share/known_hosts` 是本项目专用的 SSH 配置与主机公钥，不读取个人 SSH 配置或私钥。
- `output/share-proxy.*.log` 与 `output/share-tunnel.*.log` 记录运行情况，不记录访问密码。`data/`、`output/`、`.tools/` 已由项目忽略规则排除。

首次缺少主机公钥记录时，启动脚本通过 `ssh-keyscan` 记录 `localhost.run` 的主机公钥，属于首次信任（TOFU）；之后必须通过该记录校验。主机公钥变更时不会自动跳过检查。

停止脚本会先核对 PID 对应的完整命令行，确认它是本项目的代理或带有指定目标、端口和专用 known_hosts 的隧道。Windows 虚拟环境启动器的子进程也逐一按同一脚本、配置和端口核对后才会结束。无法核对的进程不会被终止，也不会批量结束 Python 或 SSH。

## 排查

- 提示主服务未就绪：先打开本机网址确认系统已经启动，再运行演示脚本。
- 提示 8767 端口占用：先尝试停止本项目演示；脚本不会终止未知的占用者。
- 没有取得网址：查看 `output/share-tunnel.stderr.log`。网络需要允许到 `localhost.run` 的 SSH 出站连接；脚本不会修改防火墙或路由器设置。
- 登录后操作被拒绝：确认使用访问说明中的最新 HTTPS 网址，不使用旧域名或 HTTP 地址。
- 本机可用而公网不可用：可能是网络或免费隧道状态变化，停止后重新开启并使用新网址。

## 服务依据与范围

使用本机 Windows OpenSSH 的反向端口转发，无需安装第三方隧道客户端或注册账户。localhost.run 提供 HTTPS 入口；免费域名会定期变化且有速度限制。流式回答是否正常需要通过实际公网连接验证，不能只依据本机服务正常推断。
