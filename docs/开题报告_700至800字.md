# 中国传媒大学本科毕业论文（设计）开题报告

学院：计算机与网络空间安全学院  
专业：计算机科学与技术（2023级）  
题目：基于大模型 RAG 的校园知识问答系统设计与实现

一、选题依据与研究意义
中国传媒大学的培养方案、课程大纲及办事指南分散于不同文件，存在格式不一、版本与适用年级不同等问题。学生人工查找条款耗时，通用大模型也可能生成缺乏校内依据的回答。国外Lewis等提出检索增强生成方法，将外部知识检索与文本生成结合；国内北京智源人工智能研究院等开展中文文本向量研究，为语义检索提供基础。本课题拟结合校园资料特点，探索可追溯的知识问答流程，提升信息查询便利性，并综合运用数据库、自然语言处理和软件工程知识。

二、研究内容与技术路线
面向本校2023级计算机科学与技术专业，构建涵盖培养方案、课程大纲和通用办事文件的私有知识库。主要研究文档解析、文本清洗、切片与向量化，保存文件来源、版本、专业、年级和页码；实现自然语言问答、资料管理、原文展示和答案导出。
系统采用Python与FastAPI构建服务，SQLite存储文档及片段，BGE模型完成本地向量化，比较TF-IDF、语义检索与混合检索，并研究问题重点重排序。检索后将问题与相关片段输入DeepSeek，生成带来源编号的回答；证据不足时提示无法确认。通过适用范围筛选与引用核对减少版本混淆和无依据结论。

三、研究方法与可行性
采用文献分析、需求分析、原型开发和对照实验方法。重点解决跨页上下文丢失、正确条款漏检及引用支持不足问题。已有真实校园文件、可运行原型和模型接口，具备继续实施条件。实验将区分开发集与独立测试集，固定语料和配置，比较直接回答与不同检索方案，从证据召回、回答正确性、引用支持和响应时间等方面评价效果，人工复核生成结果。

四、进度安排与预期成果
按开题后的工作周安排：第1—2周补充文献与需求分析；第3—5周完善资料处理和检索；第6—8周优化问答界面与来源展示；第9—10周开展独立测试和结果分析；第11—12周完成论文修改与答辩准备。预期提交可运行系统、源代码、知识库样本、测试报告和毕业论文。
