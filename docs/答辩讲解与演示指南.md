# 答辩讲解与演示指南

版本：2026-10-13，配合 v0.4 原型。下面是练习材料，讲述时以自己理解和实际操作为准。最终答辩时长、PPT 和论文格式按学院要求调整。

## 六分钟讲解顺序

| 时间 | 讲什么 | 展示什么 |
|---|---|---|
| 0:00–0:40 | 校园文件分散，普通模型未必知道指定学校和版本的规定 | 题目、服务对象：2023级计算机科学与技术 |
| 0:40–1:30 | 导入原件、解析文字、保留页码、400字符切片和60字符重叠 | 我的知识库、课程大纲片段、文档来源 |
| 1:30–2:20 | TF-IDF与BGE语义向量，先筛专业年级，再融合并按问题重点排序 | 系统架构图，设置中的检索策略 |
| 2:20–3:40 | 找到前4段证据，再让DeepSeek根据证据生成带编号的回答 | 一道办事问题，一道专业课程问题；点击来源核对原件 |
| 3:40–4:50 | 文件命中不等于条款命中，检索成功也不等于回答正确 | 检索检查页、回答核对页、旧漏检案例 |
| 4:50–6:00 | 说明已完成内容、真实开发结果与当前局限 | 图表、实验计划、总结 |

可以这样开场：本系统把培养方案、课程大纲和办事文件组成可更新的本地知识库。用户提问后，系统先筛选适用资料，再找到相关条款，将问题和证据送给大模型，并把原文位置一起展示，方便核对。

## 演示操作

1. 双击根目录的“启动系统.cmd”。如果服务已经运行，直接打开 http://127.0.0.1:8765/，不要重复启动。
2. 查看“我的知识库”。解释11份文档中有7份实际资料，4份明确标注示例；默认问答排除示例。课程大纲当前覆盖5门课。
3. 勾选“仅查看原文（不调用模型）”，输入“转专业一般在哪个学期组织？”。指出检索到的是原文件中的学期条款，结合右侧页码定位。该模式不调用生成接口。
4. 专业示例可使用首页的培养方案或数据结构考核问题，保持原文模式，核对来源与适用范围。培养方案原文有个别数字关系待学校确认；不要自行用计算值替换原文。
5. 如果现场网络和API额度允许，取消原文模式后发送一题，展示真实生成结果与原文。每次发送可能产生费用；接口失败时如实展示错误，随后回到原文模式。
6. 点击“复制回答”或“导出回答与依据”，说明导出含问题、回答、原文和版本位置。
7. 打开“检索检查”，运行19题离线检查，解释证据命中、Recall@4、MRR。当前开发题证据均进入前4条，MRR约0.974；这些题参与过开发，不能称独立测试准确率。
8. 打开“回答核对”，默认选择含路由修正的已保存记录。同题四组答案可并排查看。展开依据，说明助手初评和用户评分分开保存；未经核对的评分不要当正式结果。查看这页不会重新调用模型。

没有网络时，可以演示本地检索、原件、离线指标和保存的75次生成记录。清楚说明哪些是现场操作，哪些是历史记录。当前聊天只在页面内存中，刷新后聊天会清空。

## 常见提问及回答要点

| 问题 | 应理解的回答 |
|---|---|
| 为什么用RAG？ | 校园规定来自指定文件，更新知识库比重新训练生成模型更适合当前工程范围，并能展示来源；RAG仍可能检索错误或生成错误。 |
| 有没有训练大模型？ | 没有。使用固定BGE编码模型和DeepSeek生成接口，工程工作是资料处理、筛选检索、证据组织、接口和评价。 |
| 向量是什么？ | 文本经编码器变成数值数组，当前BGE每段512维；问题也编码，然后用归一化向量的点积比较相似程度。 |
| TF-IDF与语义检索有什么区别？ | 前者重视出现的字符词组，适合名称和明确用词；语义编码可处理部分改写，但相似内容不一定包含目标细节。 |
| 为什么400字符和重叠60字符？ | 是当前短篇教学文件原型的配置，用于控制上下文长度并保留相邻内容；不是证明最优的参数，需要独立验证。 |
| 混合与重排序如何实现？ | RRF按词面和语义排名融合。新增规则再结合问题重点、文件主题及所问信息类型排序；没有训练交叉编码器。 |
| 为什么不用专门向量数据库？ | 当前134片段，SQLite保存资料、内存向量做余弦检索已足够演示；扩大规模时再评估专门索引与增量更新。 |
| 学校版本与专业如何处理？ | 保留来源、版本、专业、年级和参考标记，检索先筛范围；通用文件适用对象还要看正文，空字段不自动代表不适用。 |
| 能否保证没有幻觉？ | 不能。提示约束和编号检查只是辅助，需要逐条核对事实、关键条件和引用支持。 |
| 100%是什么指标？ | 当前19道开发题的标注证据在前4条出现，平均片段Recall@4为1.0；不是生成回答准确率，也不是独立测试结果。 |
| 四组对照为什么还需正式实验？ | 旧批次直接组遗漏学校背景，又有开发中修正，不能公平证明提升。新脚本统一背景并平衡顺序，候选题审核后再冻结执行。 |
| 私有知识库是否完全离线？ | 原件、片段和Embedding在本机；开启外部生成时会发送问题与检索片段。原文模式可本地使用。 |

## 交稿前本人练习

能独立启动系统、查看一个片段、解释一条来源、区分三种检索与规则重排序，说明一处失败和一个指标的含义。阅读论文技术初稿并修改成自己的理解，按导师要求明确AI辅助情况。学院模板、最终材料与独立人工评分是当前仍需本人参与的部分。
