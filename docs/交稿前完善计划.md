核对日期：2026-10-13。面向中国传媒大学2023级计算机科学与技术本科毕业设计，当前交付范围为本机运行的校园知识问答系统。

当前 v0.4 优化状态：已完成问题重点规则重排序、条款级统一检索评价、回答核对与评分页面、原文模式和答案导出、论文技术初稿与架构图、答辩指南、备份恢复演练和不含凭据的交付准备。19道开发题标注证据均进入前4条，只能作开发修复记录。

完整变更和材料见 [整体优化记录](整体优化记录.md)、[答辩指南](答辩讲解与演示指南.md) 与 `output/论文技术初稿.docx`。最终验证详情见 `output/optimization-verification.json`。

## 优化前的问题与处理依据

以下表格保留本轮开始时的缺口，完成状态以上面的 v0.4 说明和整体优化记录为准；它用于解释为什么做这些改动。

|---|---|---|---|---|
| 高 | 正确条款检索 | 证明代办、学位办法施行日期、转专业学期等在库中，但某些方案前4条未检出 | 在19道开发题及另外的验证题上比较切片、候选数量和融合排序；保留TF-IDF基线；必要时研究重排序 | 助手实施与记录。报告正确片段命中与失败原因，保留真实结果，不以删失败题提高指标 |
| 高 | 页面检索检查 | 当前按文件名判命中，默认K=3；正式脚本按证据片段评价，K=4。页面路径没有使用问答共享的类别路由 | 区分文件命中、证据片段命中和答案评分；页面与实验采用相同范围、路由和配置 | 助手修改与验证。不能把文件命中100%展示为回答正确率100% |

| 高 | 论文模板与提交要求 | 尚未拿到学院本届正式模板与具体材料要求 | 获取本人专业适用的模板、提交时间、格式和需交材料，按真实要求定稿 | 需本人或导师提供/确认；不能用往届模板推定本届要求 |

## 有时间再做的体验改进

答案导出已完成。会话历史、流式显示、用户反馈和更多课程资料可按实际需求继续扩展，排在实验与论文之后。多人登录、文档权限和公网部署需按导师的实际交付要求确定范围。

当前题集按用户要求删除了无依据题。保留系统证据不足时提示无法确认的行为，但不计算未测试的无依据拒答率。后续如选择研究该指标，需另行明确题集范围，不能把被删除题默默加回正式集。

## 需要本人参与的事项

1. 确认学院本届论文模板、提交日期和需交材料。
2. 对新题标签与部分答案评分进行独立人工复核；原19题的题目核对无需重复。
3. 练习操作和答辩解释，确保能说明系统实际实现与局限。
4. 后续正式API实验在计划具体化后，另行确定可用额度与请求上限。

目前无需购买GPU、重新注册模型账号或重复寻找同一批文件。若扩大目标到全部专业课程、先修关系或精确考核百分比，才需要补充相应资料；是否扩大按导师要求和交稿时间决定。

推进顺序：修正检索检查与开发漏检 → 准备并复核题集 → 冻结配置与正式对照 → 评分和论文结果 → 交付、演示与答辩。论文需求、设计与实现章节可与前面的技术工作同时推进。
