# 文献阅读清单

以下来自原论文或作者来源，已核对链接。预印本不假定已发表的期刊、卷期或页码；最终引用格式按学校要求再整理。

| 文献 | 主要阅读用途 | 原文 |
|---|---|---|
| Lewis 等，2020，Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks | 理解检索与生成结合的基本思路 | https://arxiv.org/abs/2005.11401 |
| Gao 等，2023，Retrieval-Augmented Generation for Large Language Models: A Survey | 架构、检索、生成和评估的整体脉络 | https://arxiv.org/abs/2312.10997 |
| Reimers、Gurevych，2019，Sentence-BERT: Sentence Embeddings using Siamese BERT-Networks | 为什么可以把文本转为可比较的语义向量 | https://arxiv.org/abs/1908.10084 |
| Karpukhin 等，2020，Dense Passage Retrieval for Open-Domain Question Answering | 查询编码器、文档编码器和稠密检索 | https://arxiv.org/abs/2004.04906 |
| Xiao 等，2023，C-Pack: Packed Resources For General Chinese Embeddings | 中文向量模型与评测数据，结合本项目 BGE 使用 | https://arxiv.org/abs/2309.07597 |
| Cormack、Clarke、Büttcher，2009，Reciprocal Rank Fusion outperforms Condorcet and individual Rank Learning Methods | 本项目混合检索排序融合的理论来源 | https://cormack.uwaterloo.ca/cormacksigir09-rrf.pdf |
| Es 等，2023，Ragas: Automated Evaluation of Retrieval Augmented Generation | 了解检索、回答相关性和证据支持的评估思路 | https://arxiv.org/abs/2309.15217 |
| Liu 等，2023，Lost in the Middle: How Language Models Use Long Contexts | 理解上下文排序与长度为什么影响结果 | https://arxiv.org/abs/2307.03172 |

实现文档：[BGE 模型作者页面](https://huggingface.co/BAAI/bge-small-zh-v1.5)、[Sentence Transformers](https://www.sbert.net/docs/sentence_transformer/usage/usage.html)、[RapidOCR](https://rapidai.github.io/RapidOCRDocs/main/quickstart/)、[FastAPI](https://fastapi.tiangolo.com/)。

先读 RAG 原论文/综述、Sentence-BERT 的向量检索思想，再看本项目对应代码。无需先把所有论文从头精读，也不要仅依据题目就宣称使用了其中的全部方法。
